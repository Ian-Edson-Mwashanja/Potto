# Potto

Potto is a smart road monitoring system that uses vehicle-mounted
sensors, GPS, and artificial intelligence to detect, classify,
and locate road surface damage such as potholes and cracks.

## Project Goal

The goal of Potto is to provide a low-cost and scalable way of
continuously monitoring road conditions and helping authorities
prioritize road maintenance.

## Current Development Stage

The project is currently being developed as a software prototype
using simulated sensor data. Real hardware such as an ESP32,
MPU6050 accelerometer, and GPS module will be integrated later.
